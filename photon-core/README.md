# photon-core

Ядро платформы Photon. Go, AGPL.

## Где лежат документы верхнего уровня

**Не в этом каталоге, а в корне репозитория** — на уровень выше. Их ровно пять,
и они существуют в единственном экземпляре: копия в подкаталоге начинает
отставать сразу же и молча, а обнаруживается это только на аудите. Так уже
происходило: вложенные копии в `photon-core/` разошлись с корнем по трём числам
и были удалены (`CLAUDE.md`, раздел «Полнота репозитория»).

Читать в этом порядке:

1. [`../CLAUDE.md`](../CLAUDE.md) — точка входа: текущее состояние, границы,
   метод работы.
2. [`../ARCHITECTURE.md`](../ARCHITECTURE.md) — устройство системы целиком:
   Ports & Adapters, Plugin Runtime, транспорт, C ABI, безопасность.
3. [`../DECISIONS.md`](../DECISIONS.md) — почему принято именно так (ADR).
4. [`../ROADMAP.md`](../ROADMAP.md) — фазы и их статусы.
5. [`../REPOSITORY.md`](../REPOSITORY.md) — куда физически класть файлы.

Прежняя редакция этого файла ссылалась на те же документы **относительно этого
каталога** (`./ARCHITECTURE.md` и далее) — то есть на файлы, которых здесь нет и
не должно быть. Инструкция «прочитай в этом порядке» вела в пустоту.

## Что здесь есть своего

| Каталог | Что это |
|---|---|
| `ports/` | Девять портов, **заморожены** (ADR-020). Только интерфейсы, ни одной реализации |
| `adapters/` | Реализации портов: `bbolt`, `ed25519`, `aesgcm`, `quic`, `tcp`, `googleoidc`; `pion` — пустой каталог |
| `services/` | Логика поверх портов: `account`, `autodial`, `session`, `dispatcher` |
| `protobuf/` | Photon Protocol — общий контракт Core и Bridge (ADR-025, ADR-035) |
| `docs/` | Спецификации, написанные **до** кода: `bridge-session.md`, `action-routing.md`, документы по плагинам |
| `tests/livecheck/` | Ручной прогон против живого Bridge. Не автотест, см. его README |

`IMPLEMENTATION_LOG.md` внутри реализованных пакетов — почему решения приняты
именно так и что намеренно не сделано.

## Текущая фаза

Номер фазы здесь намеренно **не записан**: он устаревает первым и молча. Прежняя
редакция утверждала «Phase 1 (Core interfaces)», когда закрыто было уже
тринадцать фаз. Источник истины — [`../CURRENT_TASK.md`](../CURRENT_TASK.md) и
[`../ROADMAP.md`](../ROADMAP.md).

## Проверка

```sh
# из этого каталога
go build ./... && go test ./... && go vet ./... && gofmt -l .

# фаззинг (пакет должен быть ровно один — таково требование -fuzz)
go test ./adapters/tcp/... -fuzz=FuzzDecodeFrame -fuzztime=30s
```

## Правило для контрибьюторов

`ports/` содержит только интерфейсы. Ни одной реализации — они живут в
`adapters/`. Менять порт — только через новый ADR (ADR-020), сначала пройдя
фильтр: решается ли задача внутри адаптера; ограничение это конкретной
библиотеки или потребность ядра.
